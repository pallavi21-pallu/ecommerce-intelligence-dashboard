# E-Commerce Intelligence Dashboard

## Project Overview
An interactive e-commerce analytics dashboard built using Python and Streamlit. It helps analyze sales performance, understand customer purchasing behavior, and generate business insights through interactive visualizations.

## Features
- Sales analytics and revenue tracking
- Interactive charts using Plotly
- Customer segmentation using RFM analysis
- Customer clustering using the K-Means machine learning algorithm
- Business insights and recommendations
- Interactive filters and CSV downloads

## Technologies Used
- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- Scikit-learn

## Installation and Usage

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Install the required libraries:

   `python -m pip install -r requirements.txt`

4. Start the dashboard:

   `python -m streamlit run app.py`

5. Open the local URL displayed in the terminal, usually `http://localhost:8501`.

## Dataset
The current version generates synthetic e-commerce transaction data for demonstration and analysis. Results do not represent actual business transactions.
